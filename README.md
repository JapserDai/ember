# Ember

> 一个完全离线的游戏化人生管理系统。养一团火，也养你自己。

## 这是什么

Ember 是一个 Android App。你每天在上面记录真实生活里的小事——喝水、读书、整理桌面、给朋友发条消息——每做一件，火堆就旺一点，你的等级和五维属性就涨一点。

它不是待办清单，也不是纯粹的 RPG 游戏。它想解决的是：**知道该做什么，但坚持不下来。**

## 三条设计底线

1. **不惩罚。** 不掉等级、不没收东西、不死亡。断签了可以修，修不了也只是从头开始数，你的历史一直在。
2. **不联网。** 没有账号、没有服务器、没有社交、不申请网络权限。数据只在这台手机上。
3. **不评判。** App 只记录，不指责。没有「你失败了」，没有「前功尽弃」，没有排行榜。

## 现状

**阶段：阶段 2 进行中（打卡闭环、备份、统计、提醒已打通）。**

已有：4 个 tab（今天 / 目标 / 回忆 / 我的，图标是手绘 SVG：火苗 / 旗 / 卡片 / 人像）、一套白底主题（照 Microsoft To Do 的 Fluent 语汇：灰底 `#FAF9F8` + 白卡片 + 圆角 4 + 一个蓝；多套主题等功能补齐再做，见 D27/D29）、**待办是卡片而不是通栏行**（圆形勾选框 + 标题 + 截止日/备注/目标一行元信息，整行不可点、只有圈可点，完成后划删除线）、右下角圆形「+」、独立设置页、**人物资料**（设置 → 资料：换头像、改名字、写一句自我介绍：名字最多 16 字、简介最多 80 字，按码点数，过全 App 的禁用词表，其余一律放行；没写简介时「我的」页不显示那一行）、**头像**（七个手绘的 16×16 像素动物：狐狸 / 猫 / 兔子 / 熊猫 / 青蛙 / 企鹅 / 猫头鹰；在设置 → 资料里左右走挑一只，库中只存一个词 `avatar_id`；纯数据，零依赖、零权限，换主题时颜色跟着主题走）、SQLite 表结构与迁移器（v7）；**打卡与撤销走真实数据库**——点一下算分、写记录、更新等级 / XP / 余烬 / 五维，首页顶部的火带随之往前烧一截并亮出「+26 XP · +3 余烬」，长按撤销会把奖励一并退回；新建任务只需要一个名字；连胜（每条习惯 + 整体）从打卡记录现算；**目标页走真实数据库**——写一句话、补一句为什么、选截止日，在详情页把任务勾上来，进度按「完成了几个 / 一共几个」现算，完成由你点；**备份能导出、也能导回**——设置 → 数据 → 备份，导出一份带信封与 sha256 校验和的 JSON 交给系统分享面板；导入是**全量替换**：先校验文件（格式 / 版本 / 列白名单 / 引用完整 / 无重复 id）、再对一遍校验和、再把当前库拍一份快照，然后在一个事务里清空重写，最后重算等级与五维。导错了走「回到导入前」，把快照整份换回来；**统计页**（我的 → 统计）只看最近三十天：有记录的天数、记了多少次拿了多少经验、四个时段的横向条、五维的横向条，外加两句观察——不报完成率、不报分母、不给建议；**记录反馈落在手指上**——点完那一下，从这一行的圆圈旁飘起「+26」，连到 3 / 7 / 30 / 100 天时，奖励那一格换成「连着 7 天了」；**提醒**（设置 → 节奏 → 提醒）——每件事各设各的时刻（08:00 / 12:00 / 20:00，或自己写一个），排给系统的是未来 7 天的一次性通知，启动时补排、换时区后重排、总数按最近优先截到 20 条；文案 20 条按「任务 + 日期」轮换，只说事实和邀请，不催、不提数字；通知无声、不弹横幅、不带角标。权限在你第一次打开某条提醒时才问，不在一打开 App 时弹。

还没接上的：连胜修复、回忆页的时间线、外观走查。

## 目标平台

**只有 Android。** 通过 EAS 云构建出 apk，在静态页面上提供下载。不上 Google Play，不上国内应用商店。

## 需要的账号

一个免费的 Expo 账号（构建用）。不需要 Google、Apple、信用卡。

## 开发环境

Windows 11。已安装 Node 24、npm 11、Git。**不需要**安装 Java、Android Studio、Android SDK——构建在 Expo 云端完成。
