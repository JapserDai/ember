# Ember

> 一个完全离线的游戏化人生管理系统。养一团火，也养你自己。

## 这是什么

Ember 是一个 Android App。你每天在上面记录真实生活里的小事——喝水、读书、整理桌面、给朋友发条消息——每做一件，火堆就旺一点，你的等级和五维属性就涨一点。

它不是待办清单，也不是纯粹的 RPG 游戏。它想解决的是：**知道该做什么，但坚持不下来。**

## 三条设计底线

1. **不惩罚。** 不掉等级、不没收东西、不死亡。断签了可以修，修不了也只是从头开始数，你的历史一直在。
2. **不联网。** 没有账号、没有服务器、没有社交、不申请网络权限。数据只在这台手机上。
3. **不评判。** App 只记录，不指责。没有「你失败了」，没有「前功尽弃」，没有排行榜。

## 现状

**阶段：0–5 全部完成；阶段 6 完成 7/9。** 只剩「商店截图」与「真机手测」——两件都只差一台真机。

**已有**：4 个 tab（今天 / **状态** / **日记** / 我的，图标是手绘 SVG；见 D48 D49）、**四套主题**（白 / 夜航 / 苔原 / 晨光，共用同一份形状，只差色板；见 D40）、**待办是卡片而不是通栏行**（圆形勾选框 + 标题 + 截止日/备注/目标一行元信息，整行不可点、只有圈可点，完成后划删除线）、右下角圆形「+」、独立设置页、**人物资料**（设置 → 资料）、**头像**（七个手绘的 16×16 像素动物，库中只存一个词 `avatar_id`）、SQLite 表结构与迁移器（**v15**）。

**状态页**（D48）：照抄人升（LifeUp）的「状态」页版式——顶部「人生等级 LV.N」+ 进度条 + 一行累计记录数，下面是五维属性（名字 + LV + 横条 + 百分比 + `余量 / 200`）与称号摘要。**属性纯展示，不参与任何计分**（D7）。五维从「我的」页搬到了这里。

**日记**（D49）：每天写一句，一天一条，写在业务日上；下面是按天的历史（点开可改）、周复盘 / 月复盘入口、关键节点、以及周 / 月复盘的历史卡（每张都能存成图片）。全空保存等于把这一天清掉。首页的历史区只装最近 60 天，右上角「看更早的」进单独的目录页（D54）——日期游标往前翻，点一天退回日记页改。

**打卡闭环**：点一下算分、写记录、更新等级 / XP / 余烬 / 五维，首页顶部的火带随之往前烧一截并亮出「+26 XP · +3 余烬」，长按撤销会把奖励一并退回；新建任务只需要一个名字；连胜（每条习惯 + 整体）从打卡记录现算，**断签有宽限券与付费修复**（`streak_bridges` 表，D38）。

**目标层**（我的 → 目标）：一句话 + 一句为什么 + 截止日，详情页挂任务，进度按「完成了几个 / 一共几个」现算。D48 起从 tab 降为二级页。

**复盘**：周复盘（三个固定问题 + 自由输入，跳过不惩罚，周日一条提醒）与月复盘（月末最后一个周六，只做「看」）。**两者都能导出**——「存成图片」出 1080px PNG（中文不截断，D43），「发成文字」出 `.txt`。

**备份**：导出带信封与 sha256 校验和的 JSON；导入是**全量替换**（校验 → 重算校验和 → 拍快照 → 事务内清空重写 → 重算派生值），导错了走「回到导入前」。

**统计**（我的 → 统计）：最近三十天有几天动过、记了多少次、四个时段的横向条、五维的横向条，外加两句观察——不报完成率、不报分母、不给建议。

**提醒**（设置 → 节奏 → 提醒）：每件事各设各的时刻，排给系统的是未来 7 天的一次性通知，启动补排、换时区重排、按最近优先截到 20 条；文案 20 条轮换，只说事实与邀请；**无声、不弹横幅、不带角标**；权限在你第一次打开某条提醒时才问。

**内容与长期循环**：称号（五维 × 三档 = 15 个，纯推导不存状态）+ 称号图鉴、商店（只卖材料）+ 材料合成（固定 3:1）、今日发现（40 条，种子化、不给数值）、四季叙事（24 段，累计天数解锁）、单人 Boss（血量 60，无死亡）、月度活动（12 个月，奖励自动发）、温柔复盘 + 任务拆解（本地模板）、关键节点、隐私页。

**新手期**：首次启动三屏引导（默认选中「喝一杯水」、最多三件、没有「跳过」）；之后**七天每天一张小卡**（D1–D7），分散在今天 / 目标 / 我的三页（目标是二级页；第 5 天那张的按钮跳到状态页），可以「知道了」，不看也不挡路。

**日常维护**（D44）：结算 → 宽限券 → 月度奖励，**冷启动与从后台回到前台都跑**；它们要说的话排成队列在首页逐条显示。

**还没做的**：商店截图（要真机）、全部功能的**真机手测**（唯一的 P0）、内容模板化（那套槽位是给「探索事件」用的，而探索事件当前没有落点）、D4 卡的「最小版本」功能、图鉴的材料与复盘两类。

## 目标平台

**只有 Android。** 通过 EAS 云构建出 apk，在静态页面上提供下载。不上 Google Play，不上国内应用商店，也不注册 Limited Distribution——纯侧载。

**品牌记号是一朵小火花**（D50）：四条粗细长短各不相同的锥形笔画，形状只在 `src/domain/spark.ts` 写一次——
App 图标 / Android 自适应图标三件套 / 通知栏单色图标 / 启动图 / favicon 由 `scripts/make-logo.ts` 从同一串坐标生成，
落地页顶栏与标签页图标内联同一串 path，界面里由 `components/SparkMark` 画。**改形状只改 `spark.ts`，再重跑一次脚本。**
底栏「今天」的火苗不是记号、是图标（描边、24 网格），两者职责不同，别混。

落地页在 [`site/`](site/)（GitHub Pages，见 D46）。它**不加载任何外部资源**：没有字体 CDN、没有统计脚本、没有追踪像素——与 App 的「不联网」是同一条立场。首屏那个火带是**真的能点的**（点圆圈记一次、长按撤销），不是一张截图。
