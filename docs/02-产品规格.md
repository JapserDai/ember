# 02 · 产品规格

> 本册描述「长什么样、怎么交互、说什么话」。写界面和文案时查这里。
> 数值规则与 `04` 必须逐项一致。

## 0. 六条不可违背的原则

1. 不死亡、不掉级、不没收资产、不做公开比较。
2. 任何一次记录不超过 3 秒、不超过 2 次点击。
3. 伙伴只表达、不评判，不影响任何数值。
4. 每个数字都能解释：为什么加、为什么减、离下一档还差多少。
5. 不联网也完整可用（本 App 根本不申请网络权限）。
6. 中文原生文案，不用翻译腔，不堆感叹号。

## 1. 三套主题

### 1.1 设计原则

三套主题是三种「被对待的方式」，不是三个配色变体。组件结构、间距节奏、信息层级完全一致，只替换颜色、圆角、阴影、字体与语气。

**所有组件只读 token，不写死颜色。** 这是硬性代码规范：任何界面里出现 `#B8502F` 这样的字面值，都是 bug。

| 主题 | 一句话气质 | 适用场景 | 主色印象 |
| --- | --- | --- | --- |
| **炉边 furnace** | 傍晚回到家，有人替你把炉火拨亮 | 低能量、夜晚、需要被接住 | 陶土橙 |
| **夜航 nightvoyage** | 深夜驾驶舱，仪表微亮，只有你和方向 | 深夜专注、独处、需要秩序 | 深海蓝 |
| **苔原 tundra** | 白天的窗边书桌，纸、铅笔和一杯水 | 白天、工作学习、轻量规划 | 苔藓绿 |

### 1.6 主题切换的数据层

`settings` 表的三个字段：

| 字段 | 类型 | 默认 | 取值 |
| --- | --- | --- | --- |
| `theme_id` | TEXT | `furnace` | `furnace` / `nightvoyage` / `tundra` |
| `theme_mode` | TEXT | `system` | `light` / `dark` / `system` |
| `reduce_motion` | INTEGER | 0 | 0 / 1 |

切换只写这三个字段，走内存态并立即持久化，不触发任何业务数据变更。主题与难度、伙伴、备份完全解耦。

**跟随系统深色**：支持。每套主题都有 Light/Dark 两套色板。`theme_mode = system` 时读取系统配色；夜航在系统模式下优先暗色（暗色是它的设计主场），炉边和苔原优先亮色，用户可手动覆盖。系统切换时用 200ms 颜色过渡，不整页重载。

## 2. 伙伴系统

### 2.1 身份

默认名「小焰」，用户可在首次引导改名（2–6 字），之后随时可改。

它是一团有意识的小火，不是宠物、不是教练、不是吉祥物。

### 2.2 状态机

五个状态：**沉睡 asleep → 打盹 dozing → 平静 calm → 精神 bright → 闪耀 glowing**。

驱动信号（只看最近行为，不累计惩罚）：

- 今日是否已记录：是则 +1 级（最高闪耀）；否则维持。
- 近 7 天记录天数：0–1 天 → 上限打盹；2–3 天 → 上限平静；4–5 天 → 上限精神；6–7 天 → 可到闪耀。
- 连续 2 天无记录 → 每日降 1 级，最低沉睡。
- 滞回：升级需满足条件持续 1 天；降级立即生效，但每天最多降 1 级，避免抖动。

**状态影响**（仅表现层）：

- 台词池与语气（沉睡时句子更短、更轻）。
- 待机动画幅度、粒子数量、光晕范围。
- 首页插画姿态与视线方向。
- 「回忆」里当天生成插画的构图。

**状态绝不影响**：XP、属性、余烬、材料、掉落概率、任务难度、任何数值计算、提醒频率。

> 这一条要写进单元测试：把 mood 改成任意值，奖励计算结果必须完全不变。

### 2.3 台词系统

一条台词 = 模板 + 槽位 + 触发条件 + 权重 + 冷却。

```json
{
  "id": "line_morning_01",
  "states": ["calm", "bright"],
  "trigger": "app_open",
  "timeWindow": ["05:00", "10:59"],
  "weight": 10,
  "cooldownDays": 3,
  "conditions": { "minStreak": 0, "maxStreak": 6, "notLoggedToday": true },
  "tone": { "furnace": "warm", "nightvoyage": "plain", "tundra": "gentle" },
  "template": "{时段问候}，{伙伴名}把火拨亮了一点。{今日提示}",
  "slots": {
    "时段问候": ["早", "早上好", "天亮了"],
    "今日提示": ["今天想先做哪一件？", "不着急，一件一件来。", "先从最小的那件开始也行。"]
  }
}
```

槽位取值来自按 tone 分组的词库，模板本身 theme-neutral，tone 只决定用哪个词库。

渲染时用种子 PRNG（种子含 `playerId + localDate + lineId + 渲染次数`）保证同一天同一句稳定。单条台词同一天最多出现 1 次，7 天内不重复同一模板。

**10 条示例台词（炉边语气）**

1. 早，小焰把炉灰拨开了，还有一点红。
2. 你来了。今天不用做很多，一件就够。
3. 昨天那件事完成了，我记着呢。
4. 有点累的话，今天可以只点一根小蜡烛。
5. 三天的火，已经很稳了。
6. 这一章走到一半了，回头看看走过的地方？
7. 没记录也没关系，火不会因为你转身就灭。
8. 今天想先做哪一件？我陪你开头。
9. 你写下的那句话，我放在回忆里了。
10. 晚了，火小一点正好。明天见。

### 2.4 记忆系统

四个桶，均为本地表，随备份导出。

| 桶 | 内容 | 保留策略 |
| --- | --- | --- |
| **identity**（身份） | 伙伴名、用户昵称、称呼偏好、主题、难度、时区、创建日期、用户写下的「为什么开始」一句话 | 长期不变 |
| **recent**（近期） | 最近 7 天记录摘要、最近一次对话、最近一次心情、最近完成的任务名、最近一次断签与修复结果 | 保留 14 天 |
| **longTerm**（长期） | 章节完成、连胜里程碑、用户主动收藏的回忆、称号 | 永久，上限 200 条，超出按重要度淘汰 |
| **world**（世界） | 当前章节与季节、已解锁地点、天气风格（本地生成）、月度活动状态、伙伴成长阶段 | 随进度更新 |

**写入规则**：只在事件发生时追加，不做推断；用户可在「我的 → 伙伴记忆」逐条删除，删除即真删。

### 2.5 成长阶段与视觉变化

| 阶段 | 名称 | 解锁条件 | 视觉变化 |
| --- | --- | --- | --- |
| 1 | 火星 | 初始 | 一小团橙红，无四肢，眼睛是两个亮点 |
| 2 | 小火 | 累计记录 30 次 | 体型 +20%，出现短小的手臂，能捧东西 |
| 3 | 稳火 | 累计记录 120 次**或**完成第 1 章 | 出现稳定外焰，可戴 1 件配饰 |
| 4 | 长明 | 累计记录 365 次**或**完成第 3 章 | 内焰分层，漂浮 3–5 个光点，可戴 2 件配饰 |
| 5 | 灯塔 | 完成第 6 章 | 光晕可照亮首页背景，可戴 3 件配饰 |

阶段只升不降；条件是「或」，取先到者。

外观由模块化部件组合：身体（5 种轮廓）× 眼睛（6 种）× 配饰（12 件）× 配色（每主题 3 套）。

### 2.6 绝不出现的文案

1. 「你失败了」「你又没做到」。
2. 「太可惜了」「差一点就……」。
3. 「连续 X 天中断，前功尽弃」。
4. 「伙伴因为你……而难过 / 受伤 / 饿死」。
5. 「别人已经……」「排行榜」。
6. 「必须」「应该」「不准偷懒」。
7. 任何倒计时式羞辱（「还剩 2 小时，否则……」）。
8. 「重置」「清零」「惩罚」出现在面向用户的正文里（设置页用中性词「难度」）。
9. 对身材、收入、婚育、学历的评价或暗示。
10. 假装有情感勒索的句子（「你不来我会消失」）。
11. 感叹号连用、颜文字轰炸、夸张拟声词。
12. 医疗或心理诊断式断言（「你有拖延症」）。

> 这份清单要放进一个常量文件，所有生成文案的代码都要过一遍这个过滤器。

## 3. 可选惩罚难度

### 3.1 三档具体规则

| 维度 | **轻松（默认，界面标注「温和」）** | 标准 | 硬核 |
| --- | --- | --- | --- |
| 收益倍率 | ×0.85 | ×1.00 | ×1.20 |
| 每月自动宽限 | **3 次** | 2 次 | **0 次** |
| 连胜修复成本 | 15 余烬 | 40 余烬 + 1 材料 | 100 余烬 + 3 材料 |
| 修复后效果 | 连胜原样保留 | 连胜保留，但当日 XP 减 30% | 连胜保留（需付费修复） |
| 断签扣余烬 | **0%（不扣）** | 5%，单日上限 30 | 10%，单日上限 80 |
| 补记窗口 | 72 小时 | 48 小时 | 24 小时 |
| 补记收益 | 100% | 70% | 40% |
| 伙伴状态恢复 | 最多降 1 级，24h 内任意记录即恢复 | 最多降 1 级，需连续 2 天记录恢复 | 最多降 2 级，需连续 3 天记录恢复 |

**三档共同底线**：不死亡、不掉等级、不没收已获得资产、不清空历史、不减少属性上限、不影响已解锁内容。

> 断签扣减只在**修复期结束仍未修复**时执行。修复成功则不扣。

### 3.2 默认档位与中途切换

- **默认轻松**。首次引导第 4 屏一句话说明：「先选温和的，之后随时能改。」
- 随时可切换，入口在「我的 → 难度」。切换立即生效，只影响切换之后的业务日。
- **历史处理**：已有连胜保留；已扣的余烬不返还；已生成的回忆不改写；伙伴当前状态不因切换立刻变化；统计页标注「X 月 X 日起使用 XX 难度」。
- **禁止切换的时机**：处于 `repairable`（可修复）状态时禁止修改难度，防止「断签后切轻松」套利。
- 硬核切回其他档：需二次确认，当前契约可选择「完成」或「提前结束」；提前结束不扣任何东西，只在回忆里留一条「某契约提前结束」。

### 3.3 硬核契约

入口：难度页「签订契约」，仅在硬核档可用。

**流程**

1. 选一个核心习惯（只能选一个，且必须是每日型）。
2. 选时长：14 天或 30 天。
3. 写一句「为什么」（20–60 字，必填）。
4. 押注余烬：100 / 200 / 400 三档，只能押已有余烬，不借款、不预支。
5. 签下名字（输入伙伴名确认），生成契约卡。

**规则**

- 每天完成该习惯即打卡；漏一天，契约失败。
- 失败时押注余烬**不消失**，自动兑换成一件「灰烬纪念物」放进回忆（有外观、有日期、有那句为什么），并附一句「这次到这里，押注变成了纪念。」
- 成功完成：押注全额返还，额外奖励 1.5 倍，获得限定配饰，伙伴进入「闪耀」3 天。
- 契约期间不能删除该习惯；可暂停契约（最多 3 天，不消耗天数），暂停不视为失败。
- 同时只能有 1 份契约。

> 设计要点：即使最硬的档位，**押注也不会真的消失**，只是变成纪念物。这是「永不没收资产」原则的体现。

## 4. 任务与章节（用户视角）

### 4.1 创建任务的最小表单

**必填只有 1 项**：名称（占位「比如：睡前读 10 页」）。其余全部有默认值。

| 字段 | 默认 | 说明 |
| --- | --- | --- |
| 类型 | 每天 | 可切「每周 N 次」「只做一次」 |
| 属性 | 秩序 | 系统按关键词猜：读/学→心智，跑/睡→体魄，整理→秩序，冥想/情绪→心力，联系朋友→联结；可改 |
| 图标与颜色 | 自动 | 从 12 个图标里选，可换 |
| 提醒 | 关 | 开启后默认 20:00 |

**高级选项默认折叠**（点「更多」展开）：难度（轻/中/重，影响 XP）、目标次数、开始日期、可补记窗口、子步骤（最多 5 个）、标签、关联章节、备注。

**首次创建不展示任何高级项。**

### 4.2 章节与路标

不叫「项目」，叫「章节」；里程碑叫「路标」。用户看到的是故事线，不是表格。

- **创建章节**：一张卡片上写「这一章叫什么？」+ 一句「为什么想走这一段？」（可选）+ 系统给 3 个建议路标（可删可改）。
- **章节详情**：顶部是进度环和一句话；中间是纵向路径，路标是路径上的节点，已完成点亮；底部是「这一章的任务」，任务可拖到某个路标下。
- **路标只有三态**：未到、进行中、已到达。没有百分比，没有逾期红色。
- **完成一章触发「章节收束」**：生成一页回忆（封面、日期、完成的路标、写下的那句话）。

### 4.3 预设模板清单

首次引导让用户从下列模板中选 1–3 个，**不出现空白画布**。

**待办模板（4 个）**

1. 预约一次体检
2. 回复一条欠着的消息
3. 交一次该交的东西
4. 扔掉一件不用的东西

**章节模板（3 个）**

1. **把睡眠找回来** — 路标：固定起床时间 / 睡前不看屏幕 / 连续 7 天睡够 7 小时
2. **让桌面能呼吸** — 路标：清空桌面 / 给每样东西一个位置 / 每周五 10 分钟复位
3. **重新联系三个人** — 路标：列出三个人 / 发出第一条消息 / 见上一面

## 5. 页面与信息架构

### 5.1 底部导航（5 个）

**今天 / 章节 / 伙伴 / 回忆 / 我的**

| Tab | 职责 |
| --- | --- |
| 今天 | 记录与当日 |
| 章节 | 中长期规划 |
| 伙伴 | 状态、台词、成长、配饰 |
| 回忆 | 时间线、周报、章节收束、纪念物 |
| 我的 | 难度、主题、提醒、备份、关于 |

### 5.2 首页首屏（3 秒完成一次记录）

自上而下：

1. **顶部一句话问候**（伙伴台词，最多 18 字）+ 日期。
2. **伙伴插画**（占屏约 30%，可点，点开说话）。
3. **「今天」习惯区**：2–4 个大圆角按钮，每个显示图标、名称、连胜小字；单击 = 完成，长按 = 部分完成或跳过菜单。点击后触感反馈 + 火光粒子 + 底部出现「撤销」5 秒。
4. **今日待办**：最多 3 条，复选框 + 标题，右滑延期。
5. **底部一条「今天还可以」**：推荐一个 1 分钟微行动。

**记录路径：解锁 → 点一下习惯 = 完成。总计 1 次点击，无需进入任何页面。**

### 5.3 各页关键交互

**今天**

- 下拉出现「补记昨天」（仅难度允许时）。
- 习惯按钮左侧小圆点表示今日状态；完成时圆点填充并轻微放大。
- 顶部伙伴可长按 1 秒「摸摸」，只播动画，不加数值。

**章节**

- 卡片列表按「进行中 / 未开始 / 已完成」分组。
- 点进详情是纵向路径；路标可拖动排序；任务可长按拖到路标。
- 右上角「+」直接新建，默认给 3 个建议路标。

**伙伴**

- 上半屏插画 + 状态词 + 今日一句台词。
- 中部成长条：当前阶段、距下一阶段还差多少次记录。
- 下部配饰架：已解锁/未解锁，点击穿戴，最多 3 件。
- 「记忆」入口：四个桶分页展示，可逐条删除。

**回忆**

- 时间线倒序，卡片式：日期、事件类型、缩略插画、一句话。
- 周报卡：本周记录数、最稳的习惯、最常出现的时段、一句总结。
- 章节收束页单独全屏展示。
- 顶部筛选：全部 / 里程碑 / 周报 / 纪念物 / 对话。

**我的**

- 分组列表：外观（主题、深色模式、动效）、节奏（难度、提醒、日界）、数据（备份、导入、清空）、关于。
- 难度页有对比表与当前档位标记。
- 备份页：导出 JSON、导入、最近一次备份时间、导入前自动快照提示。

### 6.3 流失召回（无推送也能做）

App 再次打开时判断间隔：

| 间隔 | 表现 |
| --- | --- |
| 1–2 天 | 伙伴「打盹」状态，一句「火小了一点，还在。」 |

## 7. 内容模板系统

### 7.1 一条探索事件模板的 JSON 结构

```json
{
  "id": "evt_lighthouse_dusk_001",
  "version": 1,
  "type": "explore",
  "slots": {
    "location": "lighthouse",
    "mood": ["quiet", "tired"],
    "attribute": "mind",
    "season": ["autumn", "winter"],
    "outcome": ["small_gain", "insight"]
  },
  "title": "{地点}的{时段}",
  "body": "{开场}你在{地点}停下。{细节}。{收束}",
  "fragments": {
    "开场": ["风把门吹得轻响。", "灯还没亮。"],
    "细节": ["桌上有一本翻到一半的书", "窗外的海是铅灰色"],
    "收束": ["你坐了一会儿，什么也没做。", "你记下一句话，然后合上本子。"]
  },
  "rewards": { "xp": 12, "ember": 3, "attribute": { "mind": 1 } },
  "weight": 8,
  "cooldownDays": 14,
  "requires": { "minLevel": 2, "chapter": null },
  "excludes": ["evt_lighthouse_dusk_002"],
  "tags": ["solitude", "night", "no_dialogue"]
}
```

**字段说明**

- `slots`：五个维度（地点 5 × 情绪 4 × 属性 5 × 季节 4 × 结果 3），用于检索与组合，不直接拼进正文。
- `fragments`：真正用于渲染的句段库，按语义槽分组，每组 2–4 条。
- `rewards`：固定区间，按难度微调，**不允许随机大额**。
- `excludes`：互斥 id，避免同一晚出现两个「灯塔」。
- `tags`：供兼容性规则使用。

### 7.2 槽位与变体的组织方式

- 组合不是字符串随机拼接，而是「模板骨架 + 语义槽位」。每个槽位有 grammar 标记（名词/动词短语/形容词），只允许同标记互换。
- **兼容规则三层**：
  1. 语义互斥：tags 冲突（如 `no_dialogue` 与 `has_dialogue`）不共存。
  2. 情绪匹配：事件 mood 必须包含用户当日心情，或为空（通用）。
  3. 句式去重：同一模板 14 天内只用一次；同一 fragments 组内的句子，7 天内不重复。
- **生成流程**：筛选候选 → 按 weight 加权 → 种子 PRNG（`playerId + localDate + eventId`）抽取 → 组装 → 二次校验（长度 40–120 字、无禁用词、无重复句）→ 失败则回退到通用池。
- **安全**：所有 fragments 预先人工审校；上线前跑一遍禁用词表（与 2.6 同一份）。

## 8. 本地规则引擎（原「AI 辅助」）

### 8.1 定位

**不联网、不需要 API Key、不申请网络权限。**

原方案考虑过接入 AI，但三个约束同时成立时它不可行：无服务器（只能让用户自己填 Key）+ 免费（不能代付）+ 面向普通用户（他们不会去申请 Key）。

所以改为**本地规则引擎**：用模板、关键词匹配和统计规则，产出「像人写的」结果。效果上限低于真 AI，但对「不联网也完整可用」这条硬约束是唯一自洽的解法。

**不标注「AI 生成」**，因为它本来就不是。界面上直接叫功能名。

### 8.2 提供的三个功能

| 功能 | 输入 | 输出 | 本地实现 |
| --- | --- | --- | --- |
| **温柔复盘** | 最近 7 天记录 | 120 字以内总结：一个模式、一件值得保留的小事、一个下周可尝试的微调 | 24 条总结模板 × 12 个变量槽位（完成率区间、最稳习惯、最常时段、断签次数、属性分布…），按记录数/完成率/时段选模板 |
| **任务拆解** | 一件拖着没做的事 | 3 个可在 15 分钟内完成的第一步 | 动词库（准备/联系/打开/写下/清理/预约）× 任务名关键词匹配；识别失败时给通用兜底：「先花 2 分钟，把这件事需要的东西列出来」 |
| **章节灵感** | 一句模糊目标 | 3 个路标建议 + 1 句「为什么值得走这一段」草稿 | 内置 30 个章节模板库，按关键词检索，返回最接近的 3 个 |

### 8.3 明确不做

- 聊天伴侣、闲聊、情感陪伴对话
- 心理诊断、情绪分析结论
- 自动创建大量任务、自动修改数值
- 读取通讯录 / 相册 / 健康数据 / 位置
- 任何形式的网络请求

### 8.4 隐私说明（原文，放在「我的 → 关于」页）

> Ember 没有任何网络权限。你的记录只存在这台手机上，不会发送到任何地方。这里没有任何 AI 服务，所有「复盘」「拆解」「灵感」都是用内置模板生成的。你可以随时导出全部数据，也可以一键删除全部数据。

## 9. 空状态与边界情况

零基础开发者最容易忽略、但用户最先撞上的地方。

| 场景 | 表现 |
| --- | --- |
| 首次打开，还没有任何任务 | 显示引导第 3 屏的模板卡片，**不是空白列表** |
| 今天所有习惯都完成了 | 伙伴进入「闪耀」，一句「今天到这儿了，剩下的时间是你的。」不推荐新任务 |
| 今天一个任务都没有 | 「今天空着。要不要放一件小事进来？」+ 3 个快捷模板 |
| 章节里一个路标都没完成 | 显示第一个路标高亮，其余灰显；不显示「0%」 |
| 连胜为 0（从未开始） | 不显示连胜数字，显示「第一天」 |
| 断签后 | 显示「历史最佳 X 天 / 累计 Y 天」，**不显示「归零」** |
| 所有章节都完成了 | 「所有章节都走到了。要不要开始新的一章？」 |
| 连续 30 天没打开 | 打开时先给「回归章节」recap，不是直接进首页 |

## 10. 无障碍与细节

| 项 | 要求 |
| --- | --- |
| 触控目标 | 最小 44×44 |
| 对比度 | 正文文字对比度 ≥ 4.5:1（三套主题的色板已按此校验） |
| 字号缩放 | 跟随系统字号，最大不超过 1.5 倍（超过会破坏布局，需在代码里限制） |
| 减少动效 | `reduce_motion = 1` 时关闭粒子、位移、缩放动画，只保留淡入淡出 |
| 深色模式 | 三套主题各自适配，不是简单反色 |
| 色盲 | 状态不能只靠颜色区分，必须配合图标或文字 |
| 触感反馈 | 打卡成功用轻触感；升级用中触感；可用设置关闭 |
