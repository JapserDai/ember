      三条底线

      这三条不是宣传语，是代码里的约束。下面每一条都写了它在实现上意味着什么。

      不扣减
      不掉等级、不没收东西、不死亡。断签了可以修；修不了也只是从头开始数， 历史一直在。断签之后，界面上任何位置都不会出现一个「0」， 也不会把过去的天数抹掉——它显示的是「有一段空档」， 旁边并排着历史最佳与累计天数。
      不联网
      App 里没有网络请求代码，构建配置里显式移除了联网权限。 你装完之后可以在系统的应用信息里查权限列表——那里确实没有「网络」。 因此也没有账号、没有同步、没有云端备份。
      不评判
      只记录，不指责。没有完成率、没有排名、没有「别人怎么样」。 统计页只报「最近 30 天有几天动过」，不报分母。 文案里有一张禁用词表，动态生成的每一句话在显示前都要过一遍。

      它不做什么

      一个产品的形状，一半由它拒绝的东西决定。下面这些是刻意不做的，不是还没做。

      • 不做排名，也不做「好友在做什么」。 比较需要一个「别人」，而这个 App 里只有你。
      • 不做断签后的扣减。 连续天数是一个读数，不是一个筹码。断了就是从头数，没有别的后果。
      • 不做数值加成。 五个属性只是记录你把时间花在哪几维，不会影响你能做多少事。 一旦它影响产出，它就会被刷。
      • 不做云端同步。 代价说在前面：手机丢了、坏了、恢复出厂，记录就没了。 所以有一个「导出备份」——一份带校验和的 JSON 文件，你自己保管。
      • 不做账号。 打开就能用，没有注册页、没有验证码、没有「登录以继续」。

      怎么装

      这个 App 不上应用商店，装的是一个 apk 文件。下载之前，手机可能会提示「此类文件可能有害」—— 那是所有非商店来源的安装包都会遇到的提示，不是这个文件有问题。

      1. 下载 apk

        点上面的下载按钮。文件会进「下载」文件夹。

      2. 允许这个来源安装

        点开文件时，系统会问要不要允许「文件」或浏览器安装应用。 允许之后就能装。装完可以把这个权限关掉。

      3. 装完打开，选一件小事

        第一次打开是三屏说明，然后让你从几个模板里挑最多三件。 默认选中「喝一杯水」。之后随时可以改。

      4. 把提醒打开（可选）

        设置 → 节奏 → 提醒，给每件事各设一个时刻。 系统会问一次通知权限——只在你想设提醒的时候问，不会一打开就弹。

      数据在哪

      全部在一台手机上，一个 SQLite 文件里。没有第二份，也没有上传。

      位置
      App 的私有目录。其他 App 读不到，你也没法用文件管理器直接打开。
      备份
      设置 → 数据 → 备份，导出一份 JSON 交给系统的分享面板 （存到网盘、发给自己、拷到电脑都可以）。导入是全量替换： 先校验文件、再核对校验和、再把当前数据拍一份快照， 所以导错了还能走「回到导入前」。
      卸载
      卸载 App 会一起删掉这个文件。删之前先导出备份。

      先记一件小事，就今天。

      这个页面本身也不加载任何外部资源：没有统计脚本、没有字体 CDN、没有追踪像素。 它和 App 是同一种东西。
